# VAST 2025 Mini-Challenge 1 — Group 3

Visual Analytics for Big Data dashboard for VAST Challenge 2025 MC1.

## Requirements

Install dependencies into a Python environment:

```bash
pip install -r requirements.txt
```

Or, if using the `datavis` conda environment:

```bash
conda activate datavis
```

## Running the Notebook

```bash
marimo run _mini_challenge_1_group3_code.py
```

This launches the dashboard in your browser as an interactive Marimo app.

To open it in **edit mode** (to inspect or modify cells):

```bash
marimo edit _mini_challenge_1_group3_code.py
```

## Data

Place the MC1 graph JSON file in the same directory as `_mini_challenge_1_group3_code.py`:

```
mini_challenge_1/
├── _mini_challenge_1_group3_code.py
├── MC1_graph.json
├── requirements.txt
└── README.md
```
